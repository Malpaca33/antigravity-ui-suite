# Changelog

All notable changes to **Antigravity UI Suite** will be documented in this file.

## [v1.5.0] - 2026-11-14

### Added
- **Font Studio** (`font-studio/`): Standalone Antigravity sidecar plugin for per-region English & Chinese typography configuration.
- Pill-based live preview UI (`index.html`) supporting Sidebar & UI, Chat Body, Input Box, and Code & Terminal.
- One-click **Apply** (CDP hot-injection + `theme.css` persistence) and **Reset** (restore native defaults).
- Retina panel screenshot (`assets/font-studio-panel.png`).

### Changed
- Renamed repository from `antigravity-usage-hud` to `antigravity-ui-suite` and updated About metadata.
- Added prominent Quick Start, Requirements, Uninstall/Rollback, and Acknowledgements sections to `README.md` and `README.zh-CN.md`.
